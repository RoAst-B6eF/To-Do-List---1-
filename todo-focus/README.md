# To-Do & Focus — frontend-прототип

Прототип задачника с авто-приоритетами и режимом фокусировки (Pomodoro).
**Бэкенд не подключён** — данные мокаются на клиенте и сохраняются в `localStorage`.

## Стек

- **Next.js 14** (App Router) + TypeScript
- **Tailwind CSS** + компоненты в стиле **shadcn/ui**
- **Framer Motion** — анимации (уезд задачи влево, пульсация «горения»)
- **Recharts** — недельный график фокуса (stacked BarChart + кастомный Tooltip)
- **next-themes** — тёмная/светлая тема

## Запуск

```bash
cd todo-focus
npm install
npm run dev
```

Открыть http://localhost:3000

## Что реализовано

- **Задачи (`/`)**: список с мок-данными, создание (диалог, описание ≤1000), удаление с
  анимацией уезда влево, отметка «выполнено».
- **Авто-приоритет по дедлайну** (взаимоисключающие категории):
  - ⚫ Просрочено (`< 0` дней) — бордовый, **пульсирует** («горит»)
  - 🔴 Красный (`≤ 3`) · 🟡 Жёлтый (`≤ 5`) · 🟢 Зелёный (`≤ 7`) · ⚪ Серый (`> 7`)
  - Флаг «Горит» (`≤ 2` дней) — отдельный бейдж/фильтр.
- **Sidebar**: Поиск · Все задачи · Сегодня · Горит · По важности (5 категорий) — со счётчиками.
- **Профиль (`/profile`)**: счётчики Выполнено / Активные / Горит / Просрочено.
- **Фокус (`/focus`)**: Pomodoro-таймер (25/5/15 ×4), свои категории фокуса,
  недельный график с разбивкой по категориям. Кнопка «Пропустить» засчитывает рабочую
  сессию в статистику — удобно для демонстрации графика.
- **Тёмная тема** + переключатель.
